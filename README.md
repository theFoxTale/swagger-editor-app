# Swagger/OpenAPI UI

## 📖 О проекте

**Swagger/OpenAPI UI** — это современное веб-приложение для редактирования, просмотра и тестирования API-спецификаций в формате OpenAPI (Swagger). Оно предоставляет удобный интерфейс с разделённым видом (редактор + просмотрщик), авторизацию, историю запросов с аналитикой, поддержку нескольких языков и генерацию cURL-команд.

Проект разработан в рамках курса [RS School](https://rs.school/) и использует один из SSR-фреймворков для обхода CORS и серверного рендеринга.

## ✨ Основной функционал

- **Редактор OpenAPI** — вставка и редактирование спецификаций в JSON/YAML, автоматическое определение формата, валидация, переключение формата.
- **Просмотрщик** — отображение всех эндпоинтов с методами, параметрами, схемами запросов и ответов.
- **Try-It-Out** — выполнение запросов к внешним API через сервер (без CORS).
- **Генерация cURL** — копирование готовой команды для любого запроса.
- **Аутентификация** — регистрация и вход по email/паролю с клиентской валидацией.
- **История и аналитика** — сохранение выполненных запросов (для авторизованных пользователей) с метриками: длительность, статус, размеры, ошибки и т.д.
- **Сохранение схем** — автоматическое восстановление последней схемы после входа.
- **Мультиязычность** — поддержка минимум 2 языков (переключатель в шапке).
- **Адаптивный интерфейс** — автоматическая смена ориентации редактора/просмотрщика в зависимости от пропорций экрана.
- **Липкая шапка** — с анимацией при прокрутке.
- **Страница «О проекте»** — информация о команде и курсе.

## 🛠 Технологии

- **Фреймворк:** [Next.js (App Router)](https://nextjs.org/docs/app) (или другой из списка)
- **Язык:** TypeScript
- **Стилизация:** CSS Modules
- **Управление состоянием:** [Zustand](https://zustand-demo.pmnd.rs/)
- **Аутентификация:** JWT (хранится в httpOnly cookie или localStorage)
- **База данных:** Supabase / PostgreSQL (?)
- **Тестирование:** Vitest + React Testing Library
- **Линтинг:** ESLint + Prettier
- **Git-хуки:** Husky + lint-staged
- **Деплой:** Vercel (или Netlify, Render)
